* Usage
Download the release WECL.tar.gz and refer the =WECL/*.html= for examples.
To be plain, just include the =boot.js=, =wecl.js= in your web, and you can
use:

#+begin_src html
  <script type="text/common-lisp">
    ;; common lisp code here
  </script>
#+end_src

or ~<script type="text/common-lisp" src="..."></script>~ to insert common
lisp code directly into the web.
